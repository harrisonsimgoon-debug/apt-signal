# 다음 작업 목록 (플랜 모드용)

위에서부터 순서대로 진행한다. 각 항목의 "플랜 모드 요청"을 VS Code Claude Code 입력창에 붙여 넣고 계획을 받는다.

## 1. 운영 연결: Supabase 와 GitHub 배포
- 목표: 체험 모드를 실제 회원·광고 서버로 바꾸고 매일 자동 배포
- 할 일: Supabase 프로젝트 생성, schema.sql 실행, 카카오·구글 로그인 설정, config.js 키, GitHub Secrets, Pages
- 플랜 모드 요청:
  > @README.md @supabase/schema.sql @web/config.js 를 읽고, Supabase 운영 연결과 GitHub Pages 배포를 내가 따라 할 수 있는 단계로 계획해 줘. 카카오 로그인 리다이렉트 주소, 첫 관리자 지정, 배포 후 확인할 화면까지 포함해 줘. 코드 변경이 필요하면 무엇을 왜 바꾸는지 적어 줘.

## 2. 다년 백테스트와 점수 모델 재검증
- 목표: 2020년부터 쌓인 데이터로 점수 가중치를 다시 고르고, 화면 적중률 수치(validation.json)를 갱신
- 플랜 모드 요청:
  > @research/aptsignal/run.py @pipeline/scoring.py @validation.json 을 읽고, store/raw 에 쌓인 다년 데이터로 워크포워드 백테스트를 돌려 점수 가중치를 다시 정하는 계획을 세워 줘. 정보 누수 방지, 기준선 비교, 결과가 기준선보다 나쁠 때의 대응을 포함해 줘.

## 3. 관심 단지와 알림
- 목표: 로그인한 사용자가 단지를 저장하고, 점수가 바뀌거나 신고가가 나오면 알림
- 할 일: favorites 테이블, 별 버튼, 내 관심 단지 목록, 주간 이메일 또는 카카오 알림톡(비용 확인)
- 플랜 모드 요청:
  > 로그인한 회원이 단지를 관심 등록하고 주 1회 변화 요약을 받는 기능을 계획해 줘. DB(RLS 포함)·화면·발송 방법을 나눠서, 비용이 드는 선택지는 비교해 줘. @supabase/schema.sql @web/account.js @web/app.js 참고.

## 4. 기업회원 광고 셀프 신청
- 목표: 승인된 기업회원이 직접 광고를 신청하고, 관리자가 검수 후 게재
- 할 일: ad_requests 테이블, 신청 화면(자리·지역·기간·이미지), 관리자 검수함, 결제(토스페이먼츠 등)는 2단계
- 플랜 모드 요청:
  > 승인된 기업회원이 광고를 신청하고 관리자가 승인하면 ads 로 게재되는 흐름을 계획해 줘. 결제는 빼고, 견적 금액만 보여주는 1단계로. @web/admin.js @web/ads.js @supabase/schema.sql 참고.

## 5. 사업자 진위 자동 확인
- 목표: 기업회원 가입 때 국세청 사업자등록 상태 조회로 휴업·폐업 사업자를 걸러냄
- 플랜 모드 요청:
  > 국세청 사업자등록정보 진위확인 API 를 Supabase Edge Function 으로 호출해 기업회원 신청 때 자동 확인하는 계획을 세워 줘. 키를 브라우저에 노출하지 않는 구조로.

## 6. 두 번째 지역 열기
- 목표: regions.json 에 지역을 추가해 같은 모델로 서브페이지 생성
- 플랜 모드 요청:
  > @regions.json @pipeline/brands.py @CLAUDE.md 를 읽고 '서울' 지역 페이지를 여는 계획을 세워 줘. 시도 이름 확인, 브랜드 사전 보강, 빌드·테스트, 허브 반영까지.

## 7. 인프라 데이터 공공 출처 전환 (필요 시)
- 목표: 카카오 약관상 저장이 어렵다면 학교·역·병원 공공 표준데이터로 교체
- 플랜 모드 요청:
  > @pipeline/infra.py 를 카카오 대신 공공 표준데이터(학교 기본정보, 도시철도역사, 병원정보서비스)로 바꾸는 계획을 세워 줘. 화면(web/app.js renderInfra)이 받는 형식은 그대로 유지해 줘.

## 8. 중개사 셀프 관리 (매물 문의 광고)
- 목표: 승인된 공인중개사가 자기 얼굴 사진·소개·담당 단지를 직접 고치고, 전화 연결 수를 확인
- 플랜 모드 요청:
  > 승인된 공인중개사 기업회원이 내 정보에서 매물 문의 광고의 사진·소개·전화번호를 고치고(관리자 검수 후 반영), 월별 노출·전화 연결 수를 보는 화면을 계획해 줘. @web/account.js @web/ads.js @supabase/schema.sql 참고.

## 9. 단지 전경 사진 모으기
- 목표: 중개사가 촬영한 단지 사진을 올리면 관리자가 승인해 단지 카드에 쓰기 (촬영자 표시)
- 플랜 모드 요청:
  > 기업회원이 단지 전경 사진을 올리고 관리자가 승인하면 photos 테이블에 반영되는 흐름을 계획해 줘. 저작권 확인 체크, 사진 크기 줄이기, 거절 사유 포함. @web/admin.js @web/media.js @supabase/schema.sql 참고.

## 출시 전 점검
- 이용약관·개인정보처리방침 전문 (법률 검토)
- 광고 단가표, 광고 심의 기준 (허위·과장 분양 광고 거절 기준)
- 개인정보 처리 위탁 고지 (Supabase, 카카오, 구글)
- 회원 탈퇴 기능 (현재 없음)
- 위치 정보 이용 안내 (내 위치는 단지 고르기에만 쓰고 저장하지 않음을 화면·방침에 명시)
- 관광공사 사진 이용 조건 확인, 중개사 얼굴 사진 동의 절차
