## 1-1. 중개사 리포트 보내기 (카카오톡 공유) — 최우선 기능
- **재검토 필요 (2026-10-28 대표 의견):** "아직은 중개사도 경쟁사로 생각됨" — 중개사 인터뷰는 보류. 중개사를 고객으로 둘지 경쟁자로 둘지 회의에서 결정한 뒤 이 항목의 우선순위를 다시 정한다.
- 목표: 승인된 공인중개사가 단지 화면에서 "고객에게 리포트 보내기"를 누르면, 중개사 프로필이 들어간 단지 리포트가 카카오톡으로 고객에게 가고, 고객은 링크를 눌러 우리 사이트로 들어온다
- 흐름: 단지 화면 버튼(승인 중개사에게만) → 리포트 주소 생성 `report.html?c={단지}&a={중개사}` → 카카오 공유(JavaScript 키, 피드 템플릿, 미리보기 이미지) → 고객이 리포트 열람(맨 위 중개사 카드: 사진·사무소·등록번호·전화·문의 / 아래 점수·시세 흐름·호가 판단·인프라 / 맨 아래 "이 지역 다른 단지 보기")
- 기록: 리포트 생성·열람·전화 클릭을 report_events 로 남기고 중개사 내 정보에 월별 숫자로 보여줌 (중개사가 효과를 확인)
- 지킬 것: 중개사 카드에 사무소 명칭·소재지·등록번호·성명·연락처 표시(공인중개사법 표시 항목), 점수 문구 규칙 동일, 카카오 JavaScript 키는 도메인 제한 후 config.js(공개 키), 고객 개인정보는 받지 않음
- 선행: 1번(Supabase 운영 연결), 카카오 앱 플랫폼에 사이트 도메인 등록
- 플랜 모드 요청:
  > 승인된 공인중개사 회원이 단지 화면에서 '고객에게 리포트 보내기'를 누르면 중개사 프로필이 들어간 단지 리포트(report.html)를 카카오톡 공유로 보내고, 고객이 열면 우리 사이트로 이어지는 기능을 계획해 줘. 열람·전화 클릭 기록(report_events, RLS 포함), 중개사 내 정보의 월별 통계, 카카오 미리보기 이미지, 공인중개사법 표시 항목까지 포함해 줘. @web/app.js @web/account.js @web/ads.js @supabase/schema.sql @docs/BACKLOG.md 참고.
